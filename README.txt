BATA — YOUR NEXT STEP STARTS HERE
Academic Brand Revitalisation Website Prototype

PROJECT FILES
- index.html       Homepage and campaign story
- collection.html  Focused formal footwear collection
- product.html     Featured product detail concept
- style.css        Shared design system and responsive styling
- script.js        Mobile navigation, filters, gallery and demo size selector
- images/          Logo extracted from the supplied Brand Guidelines PDF

HOW TO RUN
1. Keep all files in the same Bata-Brand-Revitalisation folder.
2. Double-click index.html to open the website in a modern browser.
3. Use the navigation to move between Home, Formal Collection and Featured Shoe.
4. An internet connection is required for the remote Bata product images, contextual photography and optional Google Fonts.

IMPORTANT PRODUCT MATCH NOTE
The official Bata reference images currently used are from Bata article 8256209. The supplied Amazon short link was not independently confirmed to represent the same article. The product page explicitly notes this. Verify the exact Amazon model and replace the images/specifications if necessary before submitting the project as an exact-model presentation.

LIMITATIONS
- This is an academic visual prototype, not an official Bata website or commercial store.
- No checkout, inventory, payment, cart, or live size availability is implemented.
- Product gallery, local page navigation, mobile navigation, collection filter and demonstration size validation are implemented in JavaScript.
- Images from external websites require internet access and may be affected by the source site's availability or hotlink policy. If an image fails, replace its URL with a permitted local image in images/.
- Price, product specifications and current availability are not hardcoded because the exact Amazon model match is not verified.
